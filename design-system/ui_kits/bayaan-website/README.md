# Bayaan website UI kit

Recreation of the bayaan.consultancy.firm.in homepage, built from the actual site source (`reference/bayaan-site/page.js.txt`, `Header.js.txt`, `Footer.js.txt`): sticky blurred header, arc-field hero, services grid, CardFit case-study card, values grid, dark CTA panel, midnight footer. All primitives come from `components/` via the compiled bundle.
