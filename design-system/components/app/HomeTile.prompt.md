Route tile on the CardFit home screen — one per flow (Documents & cards / Photo / Tasks).

```jsx
<HomeTile title="Documents & cards" subtitle="Scan any document or ID — both sides laid out on one page."
  icon={<span className="material-symbols-rounded">document_scanner</span>}
  iconBg="var(--accent-soft)" iconColor="var(--color-teal-700)" />
```

Vary the icon circle: teal (documents), sage `rgba(107,138,116,.15)` (photo), midnight-50 (tasks).
