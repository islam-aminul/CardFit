Pill-shaped button, the only button shape in the brand.

```jsx
<Button>Start a project</Button>
<Button variant="ghost">See our work</Button>
<Button variant="teal">Get in touch</Button>   {/* on midnight panels */}
<Button block>Next</Button>                     {/* app bottom bars */}
```

Primary = midnight-800; teal is reserved for CTAs on dark panels. Never square corners.
